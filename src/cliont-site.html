// 04 — FAQ

Questions, answered.

Is Cliont free?

Yes — Cliont is free to download and use. It's supported by a small ad banner in the app and optional cosmetic/emote purchases that support ongoing development.

What cosmetics are available?

Currently available: Emote Pack (5 emotes), Profile Theme (custom colors), and Particle Effects (custom launch particles). More coming soon!

Which Minecraft versions are supported?

Cliont manages standard Minecraft versions and can also set up Fabric-modded profiles through the built-in Fabric API installer.

How do I install it?

Download the installer from the Updates tab, run it, sign in with your Microsoft account, and create or pick a profile to launch.

Do I need a Microsoft account?

Yes — Cliont uses standard Microsoft authentication to launch Minecraft, the same way the official launcher does.

How often are updates released?

New builds are pushed as features and fixes are ready — check the Updates tab for the latest installer.
